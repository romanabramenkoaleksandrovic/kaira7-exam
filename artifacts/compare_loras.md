# База, LoRA 16 и LoRA 64

Два прогона разные, цифры из них рядом не складываю.

Одинаковые условия обучения: 982 примера, 3 эпохи, 369 шагов, lr 2e-4, косинусный scheduler, база в NF4. Ранг 16, alpha 32, RTX 4060 Ti. Ранг 64, alpha 128, RTX 3080. alpha/rank в обоих случаях 2, у второго шире матрица.
